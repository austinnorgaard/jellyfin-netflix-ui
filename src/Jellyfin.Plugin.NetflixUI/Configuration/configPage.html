Netflix UI

Requires the File Transformation plugin. Restart Jellyfin after changing these, then hard-refresh the browser (Ctrl+Shift+R) - the web client caches aggressively.

Master switch. Turn off to get stock Jellyfin back without uninstalling.
Expands a card into a mini-modal with metadata and Play / Add buttons on hover. Automatically disabled on touch devices.
Netflix uses roughly 400ms.
Adds outlined numerals to rows whose title mentions Top / Trending / Popular.
Opens items in a Netflix-style overlay instead of navigating to the detail page.
Netflix red is #e50914.
Off by default and not shipped with this plugin. Netflix Sans is a proprietary Dalton Maag typeface licensed to Netflix, so it is deliberately not redistributed here. Enabling this downloads it to your server at runtime. If your Jellyfin is reachable from the internet you are then serving that font publicly - that is your call to make. Left off, the theme uses Inter / Helvetica Neue, which is visually very close.
